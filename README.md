# Meal Recipe Finder
Meal Recipe Finder is a full-stack MERN application that enables users to discover recipes using the Edamam API. The application provides secure authentication, subscription-based access, free trial support, and online payment integration through Razorpay.

## 🚀 Features

- Secure User Registration & Login
- JWT Authentication using HTTP-only Cookies
- Search Recipes using Edamam API
- View Detailed Recipe Information
- Subscription Plans
- Three Free Recipe Search Trials
- Razorpay Payment Gateway Integration
- Protected Routes
- Responsive User Interface

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- HTTP-only Cookies

### APIs & Services
- Edamam Recipe API
- Razorpay Payment Gateway

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/IamFJ03/RecipeTracker.git
cd RecipeTracker
```

### Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the backend directory.

```env
KEY_ID=
KEY_SECRET=
JWT_KEY=
DBString=
NODE_ENV=


VITE_EDAMAM_APP_ID=
VITE_EDAMAM_APP_KEY=
```

Start the backend.

```bash
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
```

Create a `.env` file inside the frontend directory.

```env
VITE_API_URL=http://localhost:5000
VITE_RAZORPAY_KEY=
```

Start the frontend.

```bash
npm run dev
```
